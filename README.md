# FDE 交付全流程拆解图(L1 → L4 · 交互版 · 可配置)

把 Forward Deployed Engineer(FDE)交付全流程按 **7 个一级阶段 → 子流程 → 活动 → 操作要点** 四级拆解,每个步骤可点击查看「是什么 / 怎么用 / 小例子 / 相关坑位」。

**在线访问**:https://andyclouder.github.io/FDE_WorkFlow_Book/

## 三件套(全部零依赖,双击即开)

| 文件 | 角色 | 说明 |
|---|---|---|
| `app.html` | **查看页(主入口)** | 读 `data/config.js` 渲染,交互与 index.html 一致 |
| `editor.html` | **可视化编辑器** | 左树 + 右表单编辑阶段/步骤/活动/门禁/产出物/方法库/坑位库,校验 + 导出 |
| `index.html` | 稳定快照 | 最早的静态版本,内容与源码耦合,保留兜底 |
| `data/config.js` | **单一事实来源** | 全部流程内容,由编辑器维护 |
| `tools/` | 开发工具 | `serve.mjs`(本地伴生服务,保存路径全自动)、`build-config.mjs`(从 index.html 重建配置)、`test-editor.mjs`(编辑器冒烟测试) |
| `start-editor.bat` | 一键启动 | 启动伴生服务 + 打开编辑页(推荐入口) |

## 修改内容的正确姿势

1. **双击 `start-editor.bat`**(推荐)—— 自动启动本地伴生服务并打开编辑页
2. 左树选择节点 → 右侧表单编辑;底部按钮增删/上移下移(编号自动按位置重算);编辑过程**草稿自动保存**到浏览器
3. 点「校验」:悬空的方法/坑位引用、空标题等错误会被拦截
4. 点「预览」:`app.html?draft=1` 直接看草稿渲染效果
5. 点「💾 保存到文件」(或 Ctrl+S):**路径全自动**,直接写入 `data/config.js`(覆盖前自动备份为 `data/config.backup.js`),无需选择任何路径
6. 提交 git 双推

服务模式下(状态栏显示「📁 服务模式」)保存零弹窗;若不经服务直接双击 `editor.html`(file:// 模式),保存会退回「选择文件授权一次 → 之后一键直写」(Chrome/Edge),完全不支持时降级为下载 + 手动覆盖。关闭服务窗口或 Ctrl+C 即停止伴生服务。「还原配置」可放弃草稿回到文件版,「导出 JSON」可另存备份。

## 交互功能(app.html 与 index.html 一致)

- 点击任意 **阶段标题 / 出门禁 / 步骤行**,弹出详情抽屉;阶段详情含**门禁检查清单**(逐条判据 + 证据)
- 点击步骤上的 **⚠ 标注**,直接查看对应坑位详情(症状 / 成因 / 怎么堵)
- 顶部 **搜索框**:按关键词过滤步骤
- **手机端**:自动切换单列布局 + 底部抽屉
- **桌面端**:横向大图 + 缩放,可打印

## 内容结构

7 个一级阶段:项目进入与业务还原 → 需求定义与场景选择 → POC 方案与最小验证 → 方案实现与技术落地 → 评测上线与生产化 → 业务价值验收与持续运营 → 扩展复制与能力沉淀。每阶段配出门禁(G1–G7,含检查清单),底部三条横切泳道(责任线 / 协作线 / 沉淀线)。
