# FDE 交付全流程拆解图(L1 → L4 · 交互版 · 极简风)

一个纯静态、零依赖的单文件页面:把 Forward Deployed Engineer(FDE)交付全流程按 **7 个一级阶段 → 子流程 → 活动 → 操作要点** 四级拆解,每个步骤可点击查看「是什么 / 怎么用 / 小例子 / 相关坑位」。

**在线访问**:https://andyclouder.github.io/FDE_WorkFlow_Book/

## 交互功能

- 点击任意 **阶段标题 / 出门禁 / 步骤行**,弹出详情抽屉:是什么、怎么用(操作步骤)、小例子、相关坑位、相关方法(可连续跳转,支持返回)
- 点击步骤上的 **⚠ 标注**,直接查看对应坑位详情(症状 / 成因 / 怎么堵)
- 顶部 **搜索框**:按关键词过滤步骤
- **手机端**:自动切换单列布局 + 底部抽屉,触控交互
- **桌面端**:横向大图 + 缩放(+/−/适应宽度),可打印(自动隐藏工具栏)

## 内容结构

7 个一级阶段:项目进入与业务还原 → 需求定义与场景选择 → POC 方案与最小验证 → 方案实现与技术落地 → 评测上线与生产化 → 业务价值验收与持续运营 → 扩展复制与能力沉淀。每阶段配出门禁(G1–G7),底部三条横切泳道(责任线 / 协作线 / 沉淀线)。

## 来源

内容浓缩自个人 FDE 认知知识库(内部 LLM Wiki)约 40 个打法 / 概念 / 坑位页面,涉及《The Mom Test》《AI Engineering》《Escaping the Build Trap》《The Field Guide to Human Error》《Thinking in Systems》《Team Topologies》等书及 FDE 训练课程,均为提炼后的方法综述并标注出处;☆ 标注为讲者/案例口径。

## 使用

无需构建、无需联网:单个 `index.html` 文件,浏览器直接打开即可,也可发送到手机用任意浏览器打开。
